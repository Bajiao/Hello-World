# Python Fundamentals Tutorial for High School Students

## Course Overview
This comprehensive course introduces high school students to computer science fundamentals and Python programming. Students will learn essential computing concepts, operating system basics, command-line tools, version control, and Python programming fundamentals.

**Duration:** 16-20 weeks (1-2 semesters)  
**Prerequisites:** Basic computer literacy  
**Target Audience:** High school students (grades 9-12)

---

## Unit 1: Computer Science History and Foundations (Weeks 1-2)

### Learning Objectives
- Understand the evolution of computing and programming languages
- Recognize key figures and milestones in computer science
- Appreciate the impact of computing on society

### Topics Covered
1. **History of Computing**
   - Early mechanical calculators (Abacus, Pascaline, Analytical Engine)
   - Electronic computers (ENIAC, UNIVAC, IBM mainframes)
   - Personal computer revolution (Apple II, IBM PC)
   - Internet and World Wide Web development

2. **Programming Languages Evolution**
   - Assembly language and machine code
   - High-level languages (FORTRAN, COBOL, C)
   - Modern languages (Java, Python, JavaScript)
   - Why Python? (simplicity, readability, versatility)

3. **Key Figures in CS**
   - Ada Lovelace (first programmer)
   - Alan Turing (theoretical computer science)
   - John von Neumann (computer architecture)
   - Grace Hopper (compiler development)
   - Guido van Rossum (Python creator)

### Activities
- Timeline creation project
- Research presentation on a CS pioneer
- Discussion: "How has computing changed our world?"

## Unit 2: Operating Systems Fundamentals (Weeks 3-4)

### Learning Objectives
- Understand what an operating system is and its purpose
- Learn about different types of operating systems
- Understand file systems and directory structures
- Navigate and manage files effectively

### Topics Covered
1. **What is an Operating System?**
   - Definition and core functions
   - Hardware abstraction
   - Resource management
   - User interface provision

2. **Types of Operating Systems**
   - Windows (GUI-based, user-friendly)
   - macOS (Unix-based, design-focused)
   - Linux (open-source, customizable)
   - Mobile OS (iOS, Android)

3. **File Systems Concepts**
   - What is a file system?
   - File types and extensions
   - Directory/folder structure
   - Absolute vs. relative paths
   - File permissions and ownership

4. **Directory Structure**
   - Root directory concept
   - Home directories
   - System directories
   - Common folder organization

### Activities
- OS comparison chart
- File system exploration exercise
- Create organized folder structure for course work

---

## Unit 3: Command Line Interface and Linux Basics (Weeks 5-6)

### Learning Objectives
- Navigate the command line interface confidently
- Perform basic file operations using terminal commands
- Understand the power and efficiency of command-line tools

### Topics Covered
1. **Introduction to Command Line**
   - What is CLI vs. GUI?
   - Opening terminal/command prompt
   - Basic command structure
   - Getting help (`man`, `--help`)

2. **Essential Linux/Unix Commands**
   - **Navigation:**
     - `pwd` (print working directory)
     - `ls` (list files and directories)
     - `cd` (change directory)
   
   - **File Operations:**
     - `mkdir` (create directories)
     - `rmdir` (remove directories)
     - `touch` (create files)
     - `cp` (copy files)
     - `mv` (move/rename files)
     - `rm` (remove files)
   
   - **File Content:**
     - `cat` (display file content)
     - `head` (first lines)
     - `tail` (last lines)
     - `grep` (search text)
     - `find` (search files)
   
   - **System Information:**
     - `whoami` (current user)
     - `date` (current date/time)
     - `ps` (running processes)
     - `top` (system resources)

3. **File Permissions**
   - `chmod` (change permissions)
   - `chown` (change ownership)
   - Understanding permission notation (rwx)

### Activities
- Command line scavenger hunt
- Create and organize project directories
- Practice file manipulation exercises

## Unit 4: Version Control with Git (Weeks 7-8)

### Learning Objectives
- Understand the importance of version control
- Learn Git fundamentals for personal and collaborative projects
- Set up and use GitHub for project hosting

### Topics Covered
1. **Introduction to Version Control**
   - What is version control?
   - Why use version control?
   - Centralized vs. distributed systems
   - Git vs. other VCS

2. **Git Basics**
   - Installing Git
   - Configuration (`git config`)
   - Repository concept
   - Working directory, staging area, repository

3. **Essential Git Commands**
   - **Repository Setup:**
     - `git init` (initialize repository)
     - `git clone` (copy repository)
   
   - **Basic Workflow:**
     - `git add` (stage changes)
     - `git commit` (save changes)
     - `git status` (check status)
     - `git log` (view history)
   
   - **Remote Repositories:**
     - `git remote` (manage remotes)
     - `git push` (upload changes)
     - `git pull` (download changes)
   
   - **Branching:**
     - `git branch` (list/create branches)
     - `git checkout` (switch branches)
     - `git merge` (combine branches)

4. **GitHub Integration**
   - Creating GitHub account
   - Creating repositories
   - README files and documentation
   - Basic collaboration workflows

### Activities
- Set up personal GitHub account
- Create first repository
- Practice commit workflow
- Collaborate on a class project

## Success Tips for Students

1. **Practice Regularly:** Programming is a skill that improves with daily practice
2. **Read Error Messages:** They often contain clues for fixing problems
3. **Start Simple:** Break complex problems into smaller, manageable parts
4. **Use Version Control:** Commit changes frequently with meaningful messages
5. **Ask Questions:** Programming community is helpful and supportive
6. **Build Projects:** Apply concepts to personal interests and hobbies
7. **Stay Curious:** Explore beyond course requirements
