# Student Projects

This folder contains project templates and guidelines for student assignments throughout the course.

## Project Types

### Unit Projects
Small projects that reinforce specific unit concepts:
- Command-line automation scripts
- Git workflow demonstrations
- Python programming challenges
- Data processing applications

### Capstone Projects
Comprehensive final projects students can choose from:

1. **Personal Finance Calculator**
   - Budget tracking system
   - Expense categorization
   - Savings goal calculator
   - Financial reporting

2. **Text Adventure Game**
   - Interactive storytelling
   - Character inventory system
   - Save/load game functionality
   - Multiple story branches

3. **Data Analysis Tool**
   - CSV data processor
   - Basic statistical analysis
   - Data visualization (optional)
   - Report generation

4. **Student Grade Tracker**
   - Grade calculation system
   - GPA computation
   - Progress tracking
   - Academic reports

## Project Structure

Each project folder contains:
- `README.md` - Project description and requirements
- `starter-code/` - Template files to begin with
- `examples/` - Sample implementations
- `rubric.md` - Grading criteria
- `submission-guidelines.md` - How to submit work

## Getting Started

1. Choose a project that interests you
2. Read the project README thoroughly
3. Review the rubric and requirements
4. Start with the provided starter code
5. Build incrementally and test frequently
6. Document your code and process

## Submission

All projects should be submitted via:
- GitHub repository with clear commit history
- README file explaining your implementation
- Working code that runs without errors
- Documentation of challenges and solutions
