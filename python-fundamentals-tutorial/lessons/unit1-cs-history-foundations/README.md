# Unit 1: Computer Science History and Foundations

## Overview
This unit introduces students to the rich history of computing and the evolution of programming languages. Students will explore how computing has developed from simple mechanical devices to the powerful digital systems we use today.

**Duration:** 2 weeks (Weeks 1-2)  
**Total Class Periods:** 8-10 sessions

## Learning Objectives
By the end of this unit, students will be able to:
- Understand the evolution of computing from mechanical to electronic devices
- Identify key figures and milestones in computer science history
- Explain how programming languages have evolved over time
- Appreciate the impact of computing on modern society
- Recognize the foundational concepts that led to modern programming

## Key Concepts Covered

### Historical Timeline
- **Ancient Times:** Abacus and early calculation tools
- **17th Century:** Pascal's mechanical calculator
- **19th Century:** Babbage's Analytical Engine
- **1940s:** First electronic computers (ENIAC)
- **1950s:** Commercial computers (UNIVAC)
- **1970s-1980s:** Personal computer revolution
- **1990s-Present:** Internet and modern computing

### Programming Evolution
- **1940s:** Machine code (binary)
- **1950s:** Assembly language
- **1950s-1960s:** First high-level languages (FORTRAN, COBOL)
- **1970s:** Structured programming (C)
- **1980s-1990s:** Object-oriented languages (C++, Java)
- **1990s-Present:** Modern languages (Python, JavaScript)

### Key Figures
- **Ada Lovelace:** First programmer
- **Charles Babbage:** Analytical Engine designer
- **Grace Hopper:** Compiler inventor, COBOL developer
- **John von Neumann:** Computer architecture
- **Dennis Ritchie:** C programming language
- **Guido van Rossum:** Python creator

## Differentiation Strategies

### For Advanced Students
- Research additional computing pioneers
- Explore programming language syntax comparisons
- Investigate computing development in different countries
- Create multimedia timeline presentations

### For Struggling Students
- Provide timeline templates
- Use visual aids and analogies
- Offer partner work opportunities
- Focus on major milestones rather than details

### For English Language Learners
- Provide vocabulary lists with definitions
- Use visual timelines and diagrams
- Encourage native language research with English presentation
- Pair with supportive English-speaking partners

## Unit 1 Success Criteria

- Correctly identifying major computing milestones
- Explaining the progression from mechanical to electronic computers
- Describing key contributions of computing pioneers
- Creating accurate and creative timeline presentations
- Making connections between historical and modern computing
