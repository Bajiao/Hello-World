### Part B: Short Answer Sample Answers

**1. Machine code vs. Assembly:**
Machine code consists of binary numbers (0s and 1s) that computers directly understand, but it's extremely difficult for humans to read and write. Assembly language uses words and symbols to represent machine code instructions, making it much easier for programmers to understand. Assembly language was developed to make programming more accessible while still allowing direct control of the computer's hardware.

**2. Apple II Success Features:**
The Apple II was successful because it had color graphics and sound capabilities that made it appealing for both education and entertainment. It was designed to be user-friendly with a sleek case and easy setup, unlike earlier computers that required technical expertise. The computer also had expansion slots that allowed users to add new capabilities, making it versatile for different needs.

**3. Grace Hopper's Contributions:**
Grace Hopper developed the first compiler, which translated English-like instructions into machine code, making programming more accessible. She led the development of COBOL, one of the first programming languages designed for business use. Her most significant innovation was the concept of automatic programming, which allowed programmers to write instructions in something closer to natural language rather than machine code.

### Study Guide for Students

#### Key Terms to Review
- **Abacus:** Ancient calculating device using beads
- **Pascaline:** First mechanical calculator by Blaise Pascal
- **Analytical Engine:** Babbage's design for general-purpose computer
- **ENIAC:** First general-purpose electronic computer
- **Transistor:** Electronic switch that replaced vacuum tubes
- **Microprocessor:** Computer's "brain" on a single chip
- **Machine Code:** Binary instructions computers directly understand
- **Assembly Language:** Low-level programming using words instead of numbers
- **High-level Language:** Programming language closer to human language
- **Compiler:** Program that translates high-level language to machine code

#### Study Strategies
1. **Create flashcards** for key terms and dates
2. **Draw timelines** showing progression of innovations
3. **Make connections** between different innovations
4. **Use mnemonics** to remember important dates
5. **Practice explaining** concepts to family or friends
