# Activity: Computer Science Timeline Project

## Overview
Students will create a comprehensive timeline of computer science history, incorporating the key events, people, and innovations covered in Unit 1. This project reinforces learning while developing research and presentation skills.

## Learning Objectives
- Synthesize information from multiple lessons about CS history
- Develop research skills using reliable sources
- Create a visual representation of historical progression
- Present findings clearly to peers
- Understand the interconnected nature of technological advancement

## Materials Needed
- Large poster paper or digital presentation software
- Markers, colored pencils, or digital design tools
- Access to internet for research
- Printed timeline template (optional)
- Rulers for straight lines

## Project Requirements

### Timeline Scope
**Time Period:** 1600 BCE - Present Day
**Focus Areas:**
- Computing devices and machines
- Key figures and pioneers
- Programming language milestones
- Major technological breakthroughs
- Social and cultural impacts

### Required Timeline Elements

#### 1. Early Computing (1600 BCE - 1940)
**Must Include:**
- Abacus (c. 2400 BCE)
- Pascaline (1642) - Blaise Pascal
- Analytical Engine (1837) - Charles Babbage
- Ada Lovelace's contributions (1843)
- Boolean Algebra (1854) - George Boole

**Research and Add:**
- One additional early computing device
- One mathematician/inventor not covered in class

#### 2. Electronic Age (1940 - 1970)
**Must Include:**
- ENIAC (1946)
- Transistor invention (1947)
- UNIVAC I (1951)
- IBM System/360 (1964)
- ARPANET (1969)

**Research and Add:**
- One other early electronic computer
- One key figure from this era

#### 3. Personal Computer Era (1970 - 1990)
**Must Include:**
- Intel 4004 microprocessor (1971)
- Altair 8800 (1975)
- Apple II (1977)
- IBM PC (1981)
- World Wide Web (1989-1991)

**Research and Add:**
- One other personal computer model
- One software breakthrough

#### 4. Modern Era (1990 - Present)
**Must Include:**
- Linux operating system (1991)
- Python programming language (1991)
- Java programming language (1995)
- Google search engine (1996)
- Smartphone revolution (2007)

**Research and Add:**
- Two modern innovations
- One current trend in computing

### Visual Design Requirements

#### Timeline Format Options
1. **Horizontal Timeline** - Traditional left-to-right format
2. **Vertical Timeline** - Top-to-bottom format
3. **Spiral Timeline** - Creative spiral design
4. **Interactive Digital Timeline** - Using tools like Prezi or Timeline JS

#### Visual Elements
- **Color Coding:** Different colors for different categories
  - Blue: Computing devices
  - Green: Programming languages
  - Red: Key people
  - Purple: Major breakthroughs
- **Images:** Include pictures of devices, people, or concepts
- **Icons:** Simple symbols to represent different types of innovations
- **Connections:** Show how innovations built upon each other

### Research Guidelines

#### Reliable Sources
**Recommended Websites:**
- [Computer History Museum](https://www.computerhistory.org/)
- [IEEE Computer Society](https://www.computer.org/)
- [Smithsonian National Museum of American History](https://americanhistory.si.edu/collections/computing)
- [Wikipedia](https://en.wikipedia.org/) (good starting point, but verify with other sources)

**Academic Sources:**
- School library databases
- Google Scholar
- Encyclopedia Britannica online

#### Research Requirements
- **Minimum 5 sources** (at least 2 from recommended websites)
- **Fact verification** from multiple sources
- **Proper citations** using MLA or APA format
- **Primary sources** when possible (original documents, interviews)

### Information Cards
For each timeline entry, create an information card including:
- **Date:** When it happened
- **What:** Brief description of the innovation/event
- **Who:** Person or organization responsible
- **Why Important:** Impact on computing or society
- **Fun Fact:** Interesting detail about the innovation
- **Source:** Where you found the information

## Step-by-Step Instructions

### Phase 1: Planning (Day 1)
1. **Choose your timeline format** (horizontal, vertical, spiral, or digital)
2. **Create a rough sketch** of your timeline layout
3. **Assign team roles** (if working in groups)
4. **Start research** on required elements

### Phase 2: Research (Days 2-3)
1. **Gather information** on all required timeline elements
2. **Find additional innovations** to exceed minimum requirements
3. **Collect images** and visual materials
4. **Verify facts** with multiple sources
5. **Create information cards** for each timeline entry

### Phase 3: Creation (Days 4-5)
1. **Set up your timeline base** (poster or digital platform)
2. **Add major time periods** and scale
3. **Place timeline entries** in chronological order
4. **Add visual elements** (colors, images, icons)
5. **Include connecting lines** showing relationships
6. **Add title and legend**

### Phase 4: Review and Refinement (Day 6)
1. **Check for accuracy** of all dates and facts
2. **Ensure visual clarity** and readability
3. **Add final touches** and decorative elements
4. **Prepare presentation notes**
5. **Practice your presentation**

### Phase 5: Presentation (Day 7)
1. **Present your timeline** to the class (3-5 minutes)
2. **Highlight your favorite discovery** from research
3. **Explain one connection** between different innovations
4. **Answer questions** from classmates

## Assessment Rubric

### Content Accuracy (25 points)
- **Excellent (23-25):** All information is accurate and verified
- **Good (20-22):** Most information is accurate with minor errors
- **Satisfactory (17-19):** Some accurate information with several errors
- **Needs Improvement (0-16):** Many inaccuracies or missing information

### Research Quality (25 points)
- **Excellent (23-25):** Uses multiple reliable sources, proper citations
- **Good (20-22):** Uses adequate sources with mostly proper citations
- **Satisfactory (17-19):** Uses some reliable sources, incomplete citations
- **Needs Improvement (0-16):** Poor source selection or no citations

### Visual Design (25 points)
- **Excellent (23-25):** Creative, clear, and visually appealing
- **Good (20-22):** Well-organized and mostly clear
- **Satisfactory (17-19):** Basic organization, some visual elements
- **Needs Improvement (0-16):** Poor organization or difficult to read

### Presentation (25 points)
- **Excellent (23-25):** Clear, engaging, and informative
- **Good (20-22):** Clear with good information sharing
- **Satisfactory (17-19):** Basic presentation of information
- **Needs Improvement (0-16):** Unclear or incomplete presentation

## Sample Timeline Entries

### Example 1: ENIAC (1946)
- **Date:** February 14, 1946
- **What:** First general-purpose electronic computer
- **Who:** J. Presper Eckert and John Mauchly
- **Why Important:** Demonstrated that electronic computers could solve complex problems 1,000 times faster than human calculators
- **Fun Fact:** Required 18,000 vacuum tubes and consumed 150 kilowatts of power
- **Source:** Computer History Museum

### Example 2: Python (1991)
- **Date:** February 20, 1991
- **What:** High-level programming language emphasizing readability
- **Who:** Guido van Rossum
- **Why Important:** Made programming more accessible to beginners while remaining powerful for experts
- **Fun Fact:** Named after the British comedy group "Monty Python"
- **Source:** Python.org official documentation
