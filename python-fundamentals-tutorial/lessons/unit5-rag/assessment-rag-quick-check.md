# Assessment: RAG Quick Check

## Instructions
Answer the following questions to check your understanding of Retrieval Augmented Generation (RAG):

1. What are the two main components of RAG?
2. Why is RAG more reliable than a regular language model?
3. Name one real-world application of RAG.
4. Describe a situation where RAG would be especially useful.
5. What is one challenge of using RAG?

## Extension
Create a concept map showing the relationship between:
- Retrieval
- Generation
- Data sources
- User questions

## Teacher Notes
- Use as an exit ticket or formative assessment.
- Discuss answers as a class or in small groups.
