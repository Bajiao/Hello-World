# Assessment: Unit 2 Practical Examination

## Overview
This practical examination assesses students' understanding of operating systems fundamentals and file system concepts through hands-on tasks and scenario-based problems. Students will demonstrate their ability to navigate file systems, understand OS functions, and solve practical computing problems.

## Examination Details
- **Duration:** 50 minutes
- **Format:** Practical hands-on tasks + written responses
- **Total Points:** 100 points
- **Materials:** Computer with OS access, assessment worksheet
- **Type:** Individual assessment (no collaboration)

---

**Time Limit:** 10 minutes

**Scenario:** You are helping a friend understand what an operating system does. Write a brief explanation (100-150 words) that includes:

1. **Definition of an operating system**

- **Needs Improvement (0-4):** Unclear or inaccurate explanation

## Assessment Answer Key (For Instructor Use)

### Part A: System Information
**Task 1:** Answers will vary by computer
**Task 2 Sample Answer:**
"An operating system is software that manages computer hardware and software resources and provides a platform for applications to run. The OS performs several important functions including managing memory allocation and controlling input/output devices. Computers need an operating system because applications cannot directly communicate with hardware components safely and efficiently. For example, when you open multiple programs, the OS allocates memory to each program and ensures they don't interfere with each other."

## Accommodation Guidelines

### Extended Time Accommodations
- Students with documented needs receive 1.5x time (75 minutes)
- Provide quiet testing environment
- Allow breaks as needed

### Alternative Assessment Formats
- **Oral Assessment:** Students can verbally explain concepts instead of writing
- **Visual Assessment:** Use diagrams and screenshots instead of written descriptions
- **Practical Focus:** Emphasize hands-on tasks over written responses

### Technology Accommodations
- **Screen Reader Compatible:** Ensure all text is accessible
- **Large Font:** Provide enlarged text versions
- **Voice Recognition:** Allow dictation software for written responses

## Remediation and Retesting

### Students Scoring Below 70%
**Remediation Requirements:**
- Complete additional file system navigation practice
- Meet with instructor for one-on-one review
- Demonstrate understanding of missed concepts
- Complete make-up practical exercises

**Retesting Options:**
- Alternative version of practical exam
- Oral assessment with instructor
- Project-based assessment demonstration
- Peer teaching assignment

### Common Areas for Remediation
1. **Path notation confusion** - Additional practice with absolute/relative paths
2. **File permission concepts** - Review security and access control
3. **OS function understanding** - Reinforce core concepts with examples
4. **Navigation skills** - Guided practice with file system exploration
