# Unit 2: Operating Systems Fundamentals

## Overview
This unit introduces students to operating systems concepts, file systems, and directory structures. Students will learn what operating systems are, how they work, and how to navigate and manage files effectively across different platforms.

**Duration:** 2 weeks (Weeks 3-4)  
**Total Class Periods:** 8-10 sessions

## Learning Objectives
By the end of this unit, students will be able to:
- Explain what an operating system is and its core functions
- Compare and contrast different types of operating systems
- Understand file system concepts and directory structures
- Navigate file systems using both GUI and command-line interfaces
- Manage files and folders effectively
- Understand file permissions and security concepts

## Key Concepts Covered

### Operating System Fundamentals
- **Definition:** Software that manages computer hardware and software resources
- **Core Functions:** Process management, memory management, file system, I/O management
- **Types:** Desktop, mobile, server, embedded systems
- **User Interfaces:** Command-line vs. graphical interfaces

### File System Concepts
- **Hierarchical Structure:** Root directory, subdirectories, files
- **Path Navigation:** Absolute paths, relative paths, shortcuts
- **File Operations:** Create, read, update, delete, copy, move
- **Permissions:** Read, write, execute for user, group, others
- **File Types:** Executable, data, configuration, system files

### Operating System Types
- **Windows:** Microsoft's GUI-based system for personal computers
- **macOS:** Apple's Unix-based system with focus on design and user experience
- **Linux:** Open-source Unix-like systems with many distributions
- **Mobile OS:** iOS and Android for smartphones and tablets

## Differentiation Strategies

### For Advanced Students
- Set up and configure virtual machines
- Explore less common operating systems (FreeBSD, Chrome OS)
- Investigate OS internals and system architecture
- Research embedded systems and IoT operating systems

### For Struggling Students
- Use visual file system diagrams
- Provide guided navigation exercises
- Focus on one primary OS before comparing
- Use analogies (file system as filing cabinet)

### For English Language Learners
- Provide OS terminology in multiple languages
- Use visual demonstrations with minimal text
- Encourage native language research with English presentation
- Create vocabulary cards for technical terms
