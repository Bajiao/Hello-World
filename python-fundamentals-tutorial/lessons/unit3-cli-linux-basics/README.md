# Unit 3: Command Line Interface and Linux Basics

## Overview
This unit introduces students to command-line interfaces and essential Linux/Unix commands. Students will learn to navigate file systems, perform file operations, and understand file permissions using text-based commands rather than graphical interfaces.

**Duration:** 2 weeks (Weeks 5-6)  
**Total Class Periods:** 10-12 sessions

## Learning Objectives
By the end of this unit, students will be able to:
- Navigate the command line interface confidently
- Perform basic file operations using terminal commands
- Understand the power and efficiency of command-line tools
- Use essential Linux/Unix commands for file management
- Understand and modify file permissions
- Explain the advantages of CLI over GUI for certain tasks
- Troubleshoot common command-line issues

## Key Concepts Covered

### Command Line Fundamentals
- **Terminal vs Command Prompt:** Different interfaces across OS
- **Command Structure:** command options arguments
- **Navigation:** Moving through directory hierarchies
- **File Operations:** Creating, copying, moving, deleting files
- **Help Systems:** Man pages, --help flags, documentation

### Essential Commands
- **Navigation:** `pwd`, `ls`, `cd`, `find`, `locate`
- **File Operations:** `mkdir`, `rmdir`, `touch`, `cp`, `mv`, `rm`
- **Content Viewing:** `cat`, `head`, `tail`, `less`, `more`
- **Text Processing:** `grep`, `sort`, `uniq`, `wc`
- **System Info:** `whoami`, `date`, `ps`, `top`, `df`, `du`

### File Permissions
- **Permission Types:** Read (r), Write (w), Execute (x)
- **User Categories:** Owner, Group, Others
- **Numeric Notation:** 755, 644, 777, etc.
- **Symbolic Notation:** u+x, g-w, o=r, etc.
- **Security Implications:** Protecting sensitive files

### Advanced Concepts
- **Wildcards:** *, ?, [], {} for pattern matching
- **Redirection:** >, >>, <, | for input/output control
- **Environment Variables:** PATH, HOME, USER
- **Process Management:** Running, stopping, background processes

## Safety and Security Notes

### Command Line Safety
- Always verify commands before execution
- Use `ls` to check current directory
- Be cautious with `rm` and `mv` commands
- Understand the difference between `rm` and `rm -rf`

### File Permission Security
- Don't give execute permission unnecessarily
- Protect sensitive files with appropriate permissions
- Understand the risks of 777 permissions
- Use sudo/administrative access responsibly
