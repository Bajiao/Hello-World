# Python Fundamentals Tutorial Module

This module contains a comprehensive Python fundamentals course designed for high school students, including computer science history, operating systems basics, command-line tools, version control with Git, and Python programming fundamentals.

## Module Structure

```
python-fundamentals-tutorial/
├── README.md                           # This file - module overview
├── python-fundamentals-syllabus.md     # Complete course syllabus
├── lessons/                            # Individual lesson materials
├── exercises/                          # Practice exercises by unit
├── projects/                           # Student project templates
└── resources/                          # Additional learning materials
```

## Course Overview

**Duration:** 16-20 weeks (1-2 semesters)  
**Target Audience:** High school students (grades 9-12)  
**Prerequisites:** Basic computer literacy

## Units Covered

1. **Computer Science History and Foundations** (Weeks 1-2)
2. **Operating Systems Fundamentals** (Weeks 3-4)
3. **Command Line Interface and Linux Basics** (Weeks 5-6)
4. **Version Control with Git** (Weeks 7-8)
5. **Python Programming Fundamentals** (Weeks 9-12)
6. **Control Structures** (Weeks 13-14)
7. **Functions and Modules** (Weeks 15-16)
8. **File Operations and Data Processing** (Weeks 17-18)
9. **Introduction to Object-Oriented Programming** (Weeks 19-20)

## Getting Started

1. Review the complete [syllabus](python-fundamentals-syllabus.md)
2. Set up the required software (Python 3.8+, Git, Code Editor)
3. Begin with Unit 1 materials in the `lessons/` folder
4. Complete exercises in the `exercises/` folder
5. Work on projects in the `projects/` folder

## Software Requirements

- Python 3.8+ (latest stable version)
- Git (latest version)
- Code editor (VS Code, PyCharm, or similar)
- Terminal/Command Prompt access
