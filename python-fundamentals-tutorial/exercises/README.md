# Exercises

This folder contains practice exercises organized by course units.

## Structure

Each unit has its own subfolder with exercises that reinforce the concepts covered in that unit.

## Unit Organization

- `unit01-cs-history/` - Computer Science History exercises
- `unit02-os-fundamentals/` - Operating Systems exercises  
- `unit03-command-line/` - Command Line and Linux exercises
- `unit04-git-version-control/` - Git workflow exercises
- `unit05-python-basics/` - Python fundamentals exercises
- `unit06-control-structures/` - Conditional statements and loops
- `unit07-functions-modules/` - Functions and modular programming
- `unit08-file-operations/` - File handling and data processing
- `unit09-oop-intro/` - Object-oriented programming basics

## Exercise Types

- **Guided Practice:** Step-by-step exercises with solutions
- **Independent Practice:** Exercises for self-assessment
- **Challenge Problems:** Advanced exercises for extension learning
- **Real-world Applications:** Practical scenarios and use cases

## Instructions

1. Complete exercises in order within each unit
2. Check your work against provided solutions
3. Ask for help if you get stuck
4. Move to challenge problems when ready
